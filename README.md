One sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## Entry

`main.ts` writes the pitch to `/output/entry.txt`:

> Describe the app you've talked about for years, watch the agent build it in front of you, and pay nothing unless it works — your idea has only ever cost you the years you spent not trying it.

## Run

```sh
node main.ts
```

The program writes `/output/entry.txt` and validates it: valid UTF-8, one sentence, 1–240 characters.
